# ARTEx Agent Profiles for Claude Desktop

[한국어](README.md) · [English](README.en.md) · 日本語 · [简体中文](README.zh.md)

運用者が設定した ARTEx サーバーをローカルの Claude Desktop セッションから利用するための連携リポジトリです。Claude エージェントプロファイル、スキル、コマンドと Python MCP コネクターを提供します。

> コネクターは、アクセス権のある ARTEx インスタンスと評価タスクにのみ使用してください。対象リクエスト用コネクターには範囲と予算の制限がありますが、汎用スキャナーではありません。対象リクエストを有効にする前に、タスク範囲、allow/deny ルール、リクエスト予算、中止条件を確認してください。

## 内容

- `claude-cowork-plugin/agents/`: 調整、計画、評価、報告、再テスト用の役割プロファイル
- `claude-cowork-plugin/skills/`: ARTEx ワークフロー、API 調査、ブラウザーおよび範囲に関するガイダンス
- `claude-cowork-plugin/commands/`: 評価ワークフローコマンド
- `src/artex_agent/`: 読み取り専用、証拠記録、タスク設定、対象リクエスト用 MCP コネクター
- `tests/`: オフラインコネクターテスト
- `scripts/package_cowork_plugin.py`: `dist/` にプラグイン ZIP を作成
- `scripts/smoke_mcp_stdio.py`: ARTEx への書き込みや対象への接続を行わず、MCP の起動とツール一覧を確認

## 必要環境

- Python 3.11 以降
- 対応するローカルプラグイン/MCP ワークフローを利用できる Claude Desktop
- 別途インストールされ、起動している ARTEx サーバー

本リポジトリには ARTEx サーバー、Claude アカウント、API キー、認証情報、タスクデータは含まれません。Claude セッションの認証と ARTEx 独自の LLM 設定は別の実行環境です。

## ローカルコネクターの設定

1. 本リポジトリで Python 仮想環境を作成して有効化します。
2. `python -m pip install -e .` でコネクターパッケージをインストールします。
3. `claude-cowork-plugin/.mcp.json.example` をプラグインのローカル設定にコピーし、Python とソースのパスを自分のコンピューター上の絶対パスに置き換えます。
4. `ARTEX_API_BASE_URL` を ARTEx サーバーの URL に設定します。認証情報は付属の `artex-auth-store` コマンドで保存し、MCP JSON やソース管理に秘密情報を記載しないでください。
5. `python scripts/package_cowork_plugin.py` が生成するプラグイン ZIP を、使用中の Claude Desktop バージョンが対応する手順でインストールします。

サンプル MCP 設定はテンプレートです。使用前に Claude Desktop で実際のコネクター一覧と権限を確認してください。

## チェック

オフラインテスト:

```powershell
python -m unittest discover -s tests -v
```

ローカル MCP ハンドシェイク確認:

```powershell
python scripts/smoke_mcp_stdio.py
```

スモーク確認はローカル MCP プロセスを起動してツール一覧を取得するだけで、ARTEx 環境とのエンドツーエンド接続を証明するものではありません。書き込みと読み戻しのテストには指定された合成タスクを使い、合成の脆弱性 Finding は作成しないでください。

## 実行環境の境界

エージェントプロファイルは呼び出し元の Claude Desktop セッション内で実行され、設定済みのローカル MCP コネクターを利用できます。この連携は Claude サブスクリプションの認証情報を ARTEx のネイティブ planner/worker 環境に渡さず、ARTEx の無人実行を単独で有効にするものでもありません。
